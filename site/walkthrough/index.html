Short cuts

Transcript

Your first agent

This is amux. It runs your coding agents, Claude Code, Codex or Gemini, as a team you can watch, steer, and reach from anywhere. We'll start from a fresh install and build up to the whole platform.

Skip the tour for now. Click plus, then New worker. Give it a name, point it at a repo, and tell it what to do. Here that's a failing discount test in a small store API.

Create. That card is a real Claude Code session running in its own terminal. amux tracks its status, its current task, and what it costs.

Open it and you're in the live terminal. It reads the code, sees the discount was applied after tax, fixes it, and runs the tests.

You can talk to it from right here. Messages queue and land at the next safe point, even in the middle of a task.

Run a team

One agent is handy. The real gain is running several. Here are five, each in its own git worktree so they never collide: API, frontend, docs, tests, and ops.

Groups keep them organized. Filter to backend and you see only that lane.

When one needs you, it says so. The ops worker wants permission to run a command. Click the badge to see why, open the worker, and approve. It picks up right where it stopped.

The workspace tiles their terminals side by side, so you can watch the whole team at once.

Watch and steer

Inside any worker, Translate turns raw terminal output into plain English. That's the view you want when you check in from your phone.

Steering lines up a redirect while it's busy. It lands as soon as the current step finishes.

And every worker shows its token spend, task by task.

The board

As the team grows you need one shared list of work. That's the board. Agents create cards, claim them atomically so two never grab the same one, and move them as they go.

Open a card to see who owns it, what was asked, and every action the worker took. amux won't mark work done without evidence.

For a bigger outcome, start a project. Describe the result, give one lead worker the goal and a check to pass, and you review the verified work before it ships.

Turn on auto-drain and an idle worker pulls the next card from the backlog by itself.

Automate

Some work belongs on a clock. The scheduler sends a prompt to a worker every weekday at nine, every night, or just once.

Agents can add events to the calendar too, and the feed syncs to Google or Apple Calendar.

Shared context

Context is layered. Write team notes once, add rules per group, and every worker inherits both. You can always see which layer wins.

Files lets you browse and edit any worker's folder from the browser.

Beyond the repo

Agents can work outside the repo as well. The browser tab gives them a real Chrome with your saved logins, and you can watch it live.

Connectors link Gmail, Calendar, Drive, Slack and more. Any email an agent drafts waits for your approval before it sends.

Anywhere, together

All of this works on your phone. Add it to your home screen, get an alert when a worker is blocked, and approve it from wherever you are.

Invite teammates, give them scoped access, and run the same fleet together.

amux is open source and installs with one command. Start with one worker, and add the rest as you need it. Links are below.
